## Parent → child ownership change

- Before Q1, H0 contains only the grouped A8W4 GEMM and consumes routing metadata produced outside its owned source. It owns no router program.
- After Q1, grid program 0 owns the complete bounded `M x E` logits matrix, performs every row reduction and stable selection in registers, and stores the complete `M x top_k` ID/gate outputs. No second program or launch participates.
- Expert grouping remains absent: Q1 emits direct-route expert IDs and gates, not histograms, padded rows, block schedules, or gather/scatter metadata.
- The math primitive changes from no owned router to FP32 max/exp/sum/divide reductions plus iterative max/min stable selection; it introduces no GEMM, MFMA, or WMMA.
- Global traffic is one masked logits load and one ID plus one gate store per selected route. Selection state remains in registers. Q1 uses no LDS and materializes no intermediate global buffer.
- The numerical boundary is the declared input dtype to FP32 conversion before softmax, followed by FP32 gate normalization/scaling and FP32 output stores.

## Alternatives Considered

- Copying the gfx950 wave64 layout unchanged was rejected because gfx1250 routing must distribute the bounded expert row across wave32 lanes.
- Retaining the donor's optional correction-bias selection was rejected because Q2 owns that independent numerical contract.
- Replacing the donor's iterative stable selection with a host or library `topk` call was rejected because it would not test the smaller-expert-ID tie rule inside the owned device kernel.
- Splitting the bounded router across multiple workgroups was rejected because it would introduce a new synchronization/intermediate boundary instead of isolating the wave32 semantic port.
